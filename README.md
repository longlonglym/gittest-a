# 数独游戏 (Sudoku Game)

一个用 C++ 编写的命令行数独游戏，支持生成可解的数独题目、求解数独以及查看答案。

## 功能特性

- 🎯 **题目生成** — 随机生成数独题目，确保唯一解
- 🧩 **难度选择** — 支持简单、中等、困难三种难度
- 💡 **自动求解** — 使用回溯算法求解任意数独题目
- 📝 **手动输入** — 支持手动输入题目并求解
- 🎨 **格式化显示** — 带边框的 9×9 棋盘显示

## 编译与运行

### 环境要求

- g++ (支持 C++11)
- make (可选)

### 使用 Makefile

```bash
make          # 编译
make run      # 编译并运行
make clean    # 清理
```

### 手动编译

```bash
g++ -std=c++11 -Wall -O2 -o sudoku main.cpp sudoku.cpp
./sudoku
```

### Windows 下编译

```bash
g++ -std=c++11 -Wall -O2 -o sudoku.exe main.cpp sudoku.cpp
sudoku.exe
```

## 使用说明

运行程序后，会显示交互式菜单：

1. **生成新题目** — 选择难度后自动生成数独题目
2. **输入题目求解** — 手动输入 9×9 数独，程序自动求解
3. **查看当前答案** — 显示最近生成或求解的题目答案
4. **退出** — 退出程序

### 手动输入格式

每行输入 9 个字符，数字 1-9 表示已知数字，`.` 或 `0` 表示空格。

示例：
```
530070000
600195000
098000060
800060003
400803001
700020006
060000280
000419005
000080079
```

## 算法说明

- **回溯算法 (Backtracking)** — 用于生成完整棋盘和求解数独
- **随机化** — 生成时随机排列数字顺序，确保每次生成的题目不同
- **唯一解验证** — 移除格子时验证题目仍有唯一解，保证题目质量
